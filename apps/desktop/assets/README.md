# Rewind application icon

Original Rewind artwork: the existing blue accent with two backward arrows. Generated by `scripts/generate-icon.ps1` using Windows System.Drawing; no external artwork or font is used. The committed ICO includes 16, 32, 48 and 256 pixel images. The PNG is used in the window and tray. This is a beta identity candidate for Abdullah's review.

`installer.gif` replaces Squirrel's stock animation with a 600 × 340 Rewind setup card. Generate it with `powershell -NoProfile -File scripts/generate-installer-art.ps1`. The original layout uses installed Segoe UI, the existing Rewind logo, a custom text-safe palette and three subtle activity frames. `installer-preview.png` is its actual first frame. It says installation rather than downloading and contains no invented percentage; Squirrel's native taskbar still receives actual installation progress. Setup closes at completion and Squirrel opens Rewind once. A normal installed shortcut runs the app rather than repeating setup. No font asset or imaging dependency is added. Windows publisher/signing prompts remain controlled separately by the OS.
