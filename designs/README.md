This directory contains design assets and guidance for the UI/UX designer.

Required files (examples):
- wireframes/dashboard.png — low-fidelity layout of the main dashboard
- wireframes/session-inspector.png — flow for inspecting a session and recovering files
- components.md — design tokens and component specs (buttons, timeline item, modal)

Please add exportable assets (SVG, PNG) and a brief notes.md describing interaction and accessibility needs.
