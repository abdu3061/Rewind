## Assessment and inspected revisions

Rewind is **a runnable foundation with partially implemented subsystems on unmerged branches**. The local foundation is suitable for internal shell/session testing with synthetic data. It is not ready for a recording beta or public distribution. A file-change event, SQL metadata row, interface, or green CI result does not establish capture, encryption, recovery, or permission enforcement.

## Directory and implementation classification

- **Active:** root tooling, `apps/desktop`, `packages/contracts`, `packages/engine` session service, `tests/app`, `.github`; `docs` provides the current specification/ADRs and historical research.
- **Implemented but unintegrated:** merged SQLite repositories; #4 repository improvements; #5 collector/coordinator code; #6 assistant. Their availability is acknowledged even though they are not merged.
- **Incomplete/placeholders:** extension transport/extraction/permission adapters, collector/assistant baseline interfaces, snapshot/recovery/retention/key/utility services, checkpoint and query APIs.
- **Mocks/experimental:** injected window strategy and in-memory synthetic fixtures; #3 mock bridge/history and local-state interactions; #5 fallback Maps; PowerShell polling and embedded-schema compatibility workarounds. Synthetic fixtures are useful; production fallback success and fake user actions are not.
- **Duplicated/outdated:** `db/schema.sql` and migration 001 express the same schema, with a third embedded copy in #5; BrowserVisitInput appears in both contracts and collectors in #5. The old research's optional ADK/native-binding suggestions are historical, not approval to add them.
- **Potentially obsolete/legacy, investigated:** on shared main, `api/sessionManager.ts`, `api/ai/googleAdkClient.ts`, `electron/main.ts`, `electron/preload.ts`, `public/index.html`, `src/renderer.tsx`, `src/services/ipc.ts`, `src/components/{TopNav,Timeline/Timeline}.tsx`, `src/pages/Dashboard.tsx`, and `src/styles/theme.css` are TODO/throwing/null scaffolds. Forge/Vite point at `apps/desktop`, and searches found only self-references among legacy UI files. The ADK file makes no API call. Earlier cleanup already removed these; **this audit deletes no teammate implementation**. Their originals remain in main/history and should not be recreated as a second app.
- **Local material outside the tracked application:** ignored `artifacts/rewind-demo` is presentation output; ignored nested `Rewind/` is a separate historical checkout at `4bfa033`, tracking `github.com/Rxd3/Rewind.git`. Its Git status was checked and left untouched. It is not the active workspace or a second runtime service. The audit worktrees are under ignored `artifacts/audit`; dependencies and generated output are not deliverable source.

## What can be kept

Preserve the monorepo, source-workspace bundling, strict schemas, explicit preload bridge, single synchronous session service, renderer security defaults, custom protocol, inactive extension, dependency injection, parameterized SQL/foreign-key work, repository test fixtures, and mock strategies. Salvage #4 validation/query work and #5 normalization/lifecycle seams after correcting their invariants. Reuse #3 visual tokens through frontend review; do not replace the working session integration with its simulation. Keep #6 as review material until the local query/policy layer and provider contract are correct.

## Verification boundary

The screenshot and packaged tests support a readable shell and correct tested controls, not a complete accessibility or privacy certification. No real user activity, folder content, browser history, API credential or provider request was collected for this audit. Tests used generated IDs, synthetic text, in-memory databases and a disposable synthetic SQLite fixture. Only a synthetic C# window stub was used to exercise the PowerShell script. Public release, native host installation, actual monitoring, encryption and recovery remain unverified.
