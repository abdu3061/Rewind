To rerun, use an isolated checkout of the indicated branch with its lockfile dependencies. Copy a probe into its matching source directory, retaining the `.test.ts` filename (engine `audit-failure-probes.test.ts`, storage `audit-search-probes.test.ts`, assistant `audit-failure-probes.test.ts`). Run `npx vitest run <that relative file>`. Record the intentionally failing output, then remove only the copied probe from that checkout. Do not leave known-failure probes in an ordinary feature test suite until implementing their correction.

Collector/coordinator probes use fake collectors/repositories and controlled Promises. Search uses an in-memory synthetic database. Assistant uses a mocked SDK and fake timers; its synthetic key is not a credential, and it makes no network call. The probe filenames alone do not authorize native monitoring or real cloud queries. Apply schema/port changes deliberately if a future branch evolves; keep the public safety invariant, not a brittle private implementation.
