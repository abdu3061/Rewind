- Package-time Electron fuses disable Node environment injection/RunAsNode and extra file privileges, and enforce ASAR integrity/ASAR-only startup. Final `make` disables the inspector before signing/archive creation; ordinary `build` remains a test build. Hardened verifier compares ZIP/NuGet payloads and launches the release executable in a synthetic profile.
- External signing hook plumbing with fail-closed signing-required configuration, sanitized failure and signed-byte browser inventory refresh. No real certificate/signature acceptance is claimed.
- Exact runtime dependency notice inventory with upstream files/hashes; packaged Electron/Chromium notices preserved. Missing/embedded notices and original license selection remain review gates.
- Bounded fixed-code startup/service/renderer/shutdown logs; early single-instance lock and second-launch focus; renderer crash triggers acknowledged session/worker shutdown. Startup failures preserve history and show a support code.
- Fixed a P1 shutdown composition defect found in this review: a failed/pending native credential-prompt close no longer gates the worker's consent revocation/drain. Both cleanup operations start independently and both must acknowledge before Quit succeeds; pending/throw/failure/retry regressions preserve existing deadlines.
- Existing UI retained, with skip-to-content, textarea/link focus indication, minimum-height sidebar spacing and honest startup connection status. Actual six-screen minimum-size screenshots and keyboard/overflow checks; no full accessibility claim.
- Regression tests for passive installer events/shortcut failures, code-only log rotation/failure, synthetic signed-byte inventory, actual renderer-crash drain/restart and six packaged screens. [ADR 0036](../decisions/0036-windows-release-candidate.md) explains choices and limitations.
- [Windows release procedure](../windows-release.md) and [manual Gemini acceptance](../gemini-acceptance.md). CI follows sequential check/build/app/browser/document/make/verifier gates; no automatic publishing.
