# Shared contracts and handoffs

`packages/contracts/src` is the canonical public contract. Zod schemas infer the corresponding TypeScript types. Strict objects reject unexpected properties at implemented IPC boundaries. Other schemas define future boundaries; a schema alone does not authorize a file, user action, or collector.

| Area           | Convention                                                                                                                                                                                                                              |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Identity       | UUID strings, generated by the engine/composition owner. No database row IDs in public models.                                                                                                                                          |
| Time           | Canonical ISO 8601 UTC with millisecond precision, e.g. `2026-10-17T09:00:00.000Z`. UI formats in the user's locale/timezone. Event occurrence time is distinct from future internal ingestion time.                                    |
| Results        | `{ ok: true, value }` or `{ ok: false, error: { code, message } }`. No stacks, sensitive raw validation input, paths, or provider errors in public errors. Ports may use `Result<void>` internally; IPC uses cloneable concrete values. |
| Sessions       | `null` before the first start; `active`, `paused`, `ended` thereafter. Ended state remains inspectable until a new start. Only ended sessions have `endedAt`.                                                                           |
| Activity       | Discriminated `type`/`payload`, event ID, session ID, occurrence time, and source. Foreground, browser visit, file change/opened, idle, lock, capture gap.                                                                              |
| Browser visits | Chrome/Edge, bounded HTTP(S) URL/title, UTC interval, optional bounded article text after permission. No embedded URL credentials. Session linkage must be checked at ingestion.                                                        |
| Files          | File reference identity is `verified-path` or `unverified`. A file version links a file and session to captured time, SHA-256, size, and media type. Physical blob location/key material is private storage metadata.                   |
| Checkpoints    | Named manifest links immutable file-version IDs and browser-visit IDs plus engine-owned project folder references. Kept checkpoints pin the transitive artifact set.                                                                    |
| Search         | Bounded keyword/natural-language query with optional session/time filters. Each result has a typed evidence source reference, time, excerpt, and evidence label; a title-only result never becomes verified identity.                   |
| Recovery       | Engine-owned, expiring proposal ID; save-copy/overwrite mode; explicit confirmation required. Overwrite proposals/results require preservation metadata. No public execute method exists yet.                                           |
| Settings       | Fresh default: collection/cloud/article extraction off, 72 hours, proposed 2 GiB quota, no protected folders, empty exclusions. These are not persisted or editable yet.                                                                |

The engine must check relationships beyond individual schemas: event/visit session IDs agree, referenced versions exist and belong to the correct file, sources remain accessible after retention, and proposals are current, authorized, and single-use. Absolute paths need OS canonicalization and root/reparse/race checks; a string field or `verified-path` label is not sufficient.

## Public desktop API today

`window.rewind.sessions` exposes only `get`, `start`, `pause`, `resume`, `end`, and `onChanged`. Commands accept no arguments and return `Promise<Result<SessionState>>`. `onChanged` returns an unsubscribe function. Renderer consumers must remove listeners on unmount. Preload validates calls and returned data; main validates command shape plus sender/window/frame/location. Raw Electron events never cross the bridge.

The internal command channel is `rewind:session` with exactly one strict `{ action }` payload. The change channel carries a validated state snapshot to the authorized window. Main emits updates for UI and tray actions. Synchronous in-memory mutations are serialized by the main event loop; utility-process/persistent operations will need an explicit async ordering and restart protocol.

## Interfaces for parallel work

`ports.ts` defines session/activity/file/checkpoint/search repositories and the Collector lifecycle (`start`, `pause`, `resume`, `stop`). Collector context supplies session, privacy settings, an ingestion callback, and a short-lived generation ID. Future engine ingestion must reject stopped/paused/stale generations independently of collector self-report.

Storage exports the adapter boundary. Collectors exports registry/lifecycle types. Assistant exports bounded search tools, file-version lookup, and recovery proposal creation, plus an evidence answer. These modules deliberately provide no working adapter. Each owner can build a test-only fake of its port with schema-validated fixtures; keep fakes in tests, label development-only UI adapters, and never use a fake as a silent production fallback. The session tests demonstrate deterministic clock/ID injection without Electron.

Lead-approved contract PRs land before implementation PRs that require changes. Prefer additive narrow fields; update runtime schemas, type consumers, tests, and this document together. Database migrations and utility/native wire protocols have independent versioning; do not expose raw database fields to make a frontend task easier.
